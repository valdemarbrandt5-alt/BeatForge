BeatForge v0.13.1 - frontend-only Vercel deployment

Vercel:
- Root Directory: beatforge-web-v10.2
- Framework: Next.js
- No Python/Demucs service is deployed on Vercel.

Local development:
- Start backend locally on http://127.0.0.1:8000
- npm.cmd run dev

Production AI backend (later):
- Add Vercel environment variable NEXT_PUBLIC_BEATFORGE_API_URL with the public backend URL.
- Until then, production uploads fall back to the browser generator.

The backend/ directory remains in the repository so it can be deployed separately later.
